Política de Privacidad de Kimaai: for kimai Self-hosted
Última actualización: 22-10-2026

1. Introducción
Esta Política de Privacidad se aplica a la aplicación móvil Kimaai: for kimai Self-hosted (en adelante, "la App") para dispositivos Android.

La App es un proyecto de código abierto, de uso libre y gratuito, desarrollado por RoCV (en adelante, "el Desarrollador").

2. Recopilación de Información
La App NO recopila, solicita, almacena ni transmite ningún tipo de información personal ni datos del usuario.

Específicamente:

No se solicitan permisos para acceder a contactos, ubicación, cámara, micrófono o almacenamiento.

No se integran SDKs de análisis (analytics), publicidad ni reporte de fallos (crash reporting) de terceros.

No se crean cuentas de usuario ni se solicita correo electrónico.

3. Uso de Datos
Dado que la App no recopila datos, no se realiza ningún tratamiento, uso, venta ni compartición de información con terceros.

4. Servicios de Terceros
La App no utiliza servicios de terceros que puedan recopilar información de identificación personal.

5. Código Fuente y Transparencia

Cualquier persona puede verificar de forma independiente que la App no contiene mecanismos de recolección de datos.

6. Privacidad de los Menores
La App no recopila datos de ningún usuario, incluidos menores de edad. Al no existir recolección de datos, no se requiere consentimiento parental verificable.

7. Derechos del Usuario
Como no se almacena ningún dato personal, no existen datos que puedan ser accedidos, corregidos, exportados o eliminados por solicitud. El usuario tiene control total ya que no se genera ningún registro.

8. Cambios en esta Política
Si en el futuro la App modificara sus prácticas (por ejemplo, añadiendo funciones que requieran permisos), esta Política será actualizada y se notificará mediante una nueva versión en la tienda de aplicaciones y en el repositorio.
